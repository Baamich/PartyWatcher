Security and limits

In short: the chat key is the password to your chat. Here is what protects you on the site and what you need to do yourself.

What the site does by itself

  • The key works only for your channel. Your key can't write to other chats, and other people's keys don't open yours.
  • The owner can't be faked. The site adds the red plate on the nickname itself, and a bot can't “draw” it for itself.
  • Bot messages are always labeled (for example, BOT or TWITCH). Viewers can tell them from real people.
  • Limits. No more than 20 messages in 10 seconds and 100 per minute. Beyond that the site replies “429” and tells how long to wait.
  • Sizes. Text up to 500 characters, name up to 32. Everything that comes into the chat is shown as plain text, no “harmful” markup will run.

What you need to do

  1. Never show or send anyone the key or the OBS link. The link contains the key too.
  2. Don't publish bot code with the key (for example, on GitHub). Publish the code without the key.
  3. Don't open the OBS source properties on stream. The key is visible in the URL field.
  4. Add pauses between commands in the bot (like in the roulette from the bot chapter) so viewers don't flood the chat.

If the key leaked

  1. Open the studio, click ▲ Chat API, then “🔄” and confirm.
  2. The old key immediately stops accepting messages.
  3. Copy the new OBS link (“OBS link”) and replace it in the source.
  4. Put the new key into the bot and restart the bot.

Connections already opened with the old key keep showing the chat until they are restarted (they can no longer write). To cut them off right away, in OBS open the source Properties → “Refresh cache of current page”, and stop and start the bot again.

What the key can't do

  • Ban viewers, clear the chat or view the action log. That is done only in the studio under your account.
  • Read other people's data. Messages contain only the public name and text.

Anyone can read the chat on the streamer page, so the key is needed for sending messages and for the OBS link, not for reading.
