OBS widgets and the mini panel

Stream uptime, a countdown, a death counter, a follower goal, a ticker, end credits — each is a separate OBS widget. You create and set them up in the studio, the ⏱️ Widgets section, with no code. There is also the 📌 mini panel: a small window above all apps with the chat and buttons.

How to add it to OBS

  1. Open the studio → ⏱️ Widgets. On the right, pick a widget to add — its card appears.
  2. On the card, click 📋 Link for OBS. The link is copied.
  3. In OBS: Sources → ＋ → Browser. Paste the link into “URL”. Pick a size that fits the widget, e.g. 600 × 200 for a timer or 1920 × 80 for a ticker. For the sound at the end of a countdown, tick “Control audio via OBS”.

Each widget is a separate source. Everything you change in the studio (text, colors, buttons) shows up in OBS at once — no need to refresh the source.

The link contains your events key, the same as for alerts. Don't show it on stream. If it leaks, change the key in 🔔 Events → 🔄 New key and copy the widget links again.

Up to 20 widgets per channel. You can have several of one type — for example, two counters.

Settings and look

⚙ Settings on a card opens a window with a live preview on top. Everything is saved automatically.

  • Name is only for you — so two widgets of one type don't get mixed up.
  • Name for chat commands — needed when you have several widgets of one type: /count deaths and /count wins.
  • Text templates: {n} is the number; “Latest events” has {name}, {reward}, {streamer} and more (hint under the field). An empty field means the default text in the language of the link.
  • Look: font, size, weight, text and accent (bar) color, background and its opacity, padding, rounding, outline, shadow, UPPERCASE, alignment.

The preview on a card has a checkerboard behind it: that's how a transparent background looks in OBS.

Chat commands

You can control widgets right from the channel chat — on the channel page, in the studio or in the mini panel. Commands don't go to the chat; only you see the reply.

CommandWhat it does
/timer 5Start a 5-minute countdown. 90s, 1h30m, 10:00 also work. Without a time — continue where it stopped
/timer pause, /timer resetPause / back to the start
/timer +1m, /timer -30sAdd or remove time
/sw, /sw resetStopwatch: start or pause / reset
/count, /count -, /count +5, /count =10, /count resetCounter: +1, −1, +5, set to 10, reset. The same for a goal with your own number — /goal
/text Now: bossChange the text; /text with no text clears it
/ticker Follow the channel!Change the ticker
/credits, /credits stopRoll the credits / stop them

With several widgets of one type, put the widget's name after the command: /timer brb 10. Without a name the command controls the first widget of that type. Each card shows the right command.

You can allow these commands for senior moderators: 🛡️ Channel activity → Moderator permissions → “Control OBS widgets”. Off by default. What moderators did is in the action log.

📌 Streamer mini panel

The 📌 Streamer mini panel button is in “Widgets” and on the main studio page. It opens a small window that stays above all apps, even when the browser is minimized — handy while gaming.

  • On top — stream uptime, viewers and followers.
  • Chat — read and write, /commands work too.
  • Widgets — buttons for timers, counters, text and credits.
  • Events — follows, raids, rewards while the window is open.

You can resize the window — the size is remembered.

An always-on-top window works in Chrome, Edge, Opera and Yandex Browser on a computer. Firefox and Safari open a regular small window instead. Over a game the window is visible when the game runs windowed or “borderless windowed”. In exclusive fullscreen the game covers it — every such window behaves this way.

OBS dock. The same mini panel can live inside OBS: click 🧩 Mini panel in OBS (dock), in OBS open Docks → Custom Browser Docks, type any name and paste the link. Log in to your account inside the dock the first time.

✨ Custom widget

At the top right — ✨ Create your own widget. It's a widget made of lines with variables and functions: click a hint to insert it into the line under the cursor. To start, pick a template: info panel, latest events, wheel of fortune, until New Year, follower goal, “Now…”, world clock.

  • Lines — up to 6, each with its own size, boldness and color.
  • All at once or one by one (switching every N seconds), stacked or in one row, an animation when the text changes.
  • When to show: always, only while live or only offline. A line whose variable has no value yet (e.g. “latest follower” on a new channel) hides itself.
  • Progress bar: value and maximum — numbers or variables, e.g. {followers_stream} of 10.
VariableWhat it shows
{n}, {text}The widget's own number and text — changed with the card buttons, in the mini panel, with /w name and by rewards
{uptime}, {uptime_hm}, {live}Stream uptime and “Live / Offline”
{viewers}, {followers}, {followers_stream}Viewers now, followers, new followers this stream
{title}, {category}, {streamer}Stream title, category, channel name
{time}, {date}, {weekday}Time, date, weekday; time zone — {time:Europe/Berlin} or an offset {time:+3}
{last_follower}, {last_reward}, {last_reward_user}, {last_raider}, {last_raid_viewers}, {last_chatter}, {last_clip}, {last_command}, {last_streak_user}, {last_streak} …The channel's latest events
{random:1-100}, {choice:a|b|c}, {dice}, {coin}Random — stays the same until you press 🎲 “Reroll” (or /w name roll, or a reward)
{calc:{followers}+10}, {percent:{followers_stream}:10}Calculate and percent
{countdown:2026-12-31 23:59}, {countdown:20:00}Time left until a date or the next such time (by the OBS computer clock)
{upper:…}, {lower:…}UPPERCASE or lowercase

Chat command: /w name +1, /w name =10, /w name reset, /w name roll, /w name text Now: boss, /w name clear.

Widget presets

Share a good widget with others: the 📤 button on the card or 🎨 Presets → Publish → OBS widget. The type, look and settings go out (for a text widget — its text), but not your link or key. Other people's widgets are in 🎨 Presets, filter “Widgets”: Add creates a copy in your “⏱️ Widgets”, then copy its link for OBS. Removing a preset from your list also deletes the widget it created.

A preset widget can be linked to a reward: e.g. “Wheel of challenges” and the reward “Spin the wheel” (the “reroll” action). More in Rewards.

Not working?

  • OBS shows “The key doesn't match” — the events key was changed. Copy the widget link again.
  • “This widget no longer exists” — it was deleted in the studio. Create a new one and paste the new link.
  • The widget is invisible — check it has something to show: empty text, an empty ticker and “Latest events” with no events are invisible in OBS. In the studio you see grey hint text in their place.
  • No sound at the end of a countdown — turn on “Control audio via OBS” in the source and check the sound and volume in the widget settings.
