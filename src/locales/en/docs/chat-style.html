Chat styling

How to change the look of the chat in OBS: colors, font, background, size. There are two ways: a simple one (via the link) and a flexible one (via your own CSS).

Easier without code: open the Chat builder, everything is set up with the mouse there and the link is built automatically.

Way 1. Parameters in the link (the simplest)

Take the OBS link (the “OBS link” button in the “Chat API” block) and append the parameters you need to its end. Each parameter starts with &. Then paste the link into the OBS source: right-click the source → Properties → the URL field.

AppendWhat it does
&size=30Text size, a number from 10 to 80. Default: 22.
&font=ArialFont. Any font installed on your computer works. Write spaces as they are: &font=Comic Sans MS.
&color=ffe066Text color. 6 color characters without the hash.
&bg=000000Background color under each message (black). Without the hash.
&bgalpha=55Background opacity: 0 — invisible, 100 — solid. If bg is given and bgalpha is not, it is 60.
&owner=7c3aedColor of the plate on your nickname (red by default). Without the hash.
&shadow=0Remove the text shadow.
&fade=40A message disappears after 40 seconds. 0 — never disappears.
&max=15How many messages to keep on screen (5 to 100).
&layout=barView: bar — a flat bar with one message, row — a single-line ribbon.
&valign=topStick the chat to the top of the screen.
&align=centerAlignment: center or right.
&maxw=70, &opacity=80Max message width and chat opacity, in percent.
&weight=700, &italic=1Weight (400, 500, 700, 800) and italic text.
&ls=1, &lh=150Letter spacing in pixels and line height in percent.
&stroke=000000&strokew=3Letter outline: color and width (1–6).
&bg2=7c3aedSecond background color: the background becomes a gradient (needs bg).
&blur=12Blur under the plate (needs bg).
&radius=12, &pad=12, &gap=8Corner radius, inner padding, space between messages.
&bc=ffffff&bw=2Border: color and width.
&stripe=7c3aed&stripew=5Colored stripe on the left: color and width.
&glow=a855f7&glows=14Glow around a message: color and strength.
&nickmode=autoColorful viewer nicknames (like on the site).
&nickplate=1, &ncaps=1, &src=0Nickname on a colored plate, NICKNAMES IN CAPS, hide the BOT and TWITCH labels.
&anim=popAppear animation: pop, fade or none.

Where to get a color. Open any “color picker” in the browser, choose a color and copy its code like #ffe066. Write it in the link without the # sign: ffe066.

Example of a ready link (replace the key with yours):

https://partywatcher.de/overlay/chat.html#key=pwc_...&size=28&color=ffe066&bg=000000&bgalpha=55&owner=7c3aed&fade=40

Way 2. Your own CSS (for those who want more)

CSS is “styling rules”. OBS has a special field for them.

  1. In OBS right-click the chat source → Properties.
  2. Find the Custom CSS field. There is already something in it, don't delete it.
  3. Add your rules at the end (on a new line).
  4. Click OK. If the look didn't change, open Properties again and click “Refresh cache of current page”.

What the chat consists of (names you can change)

NameWhat it is
#chatThe whole list of messages
.msgOne whole message (nickname and text)
.nickNickname
.nick--ownerThe channel owner's nickname (with a plate)
.sepThe colon after the nickname
.textMessage text
.srcSource label, for example TWITCH or BOT

Variables: the simplest way in CSS

You can change one “setting” instead of a whole rule:

VariableWhat it changes
--fsText size, for example 30px
--fontFont, for example "Impact", sans-serif
--textText color
--msg-bgMessage background, for example rgba(0, 0, 0, 0.5)
--owner-bgColor of the owner's nickname plate
--text-shadowText shadow (none — no shadow)
--gapSpace between messages, for example 12px
:root {
  --fs: 30px;
  --text: #ffe066;
  --msg-bg: rgba(0, 0, 0, 0.5);
}

Ready recipes (copy and paste)

Dark “plates” under messages:

.msg {
  background: rgba(0, 0, 0, 0.55);
  border-radius: 12px;
  padding: 4px 12px;
}

Remove the TWITCH / BOT labels:

.src { display: none; }

Show only the text, without nicknames:

.nick, .sep { display: none; }

Bigger, colored nickname:

.nick {
  color: #ffd166 !important;
  font-size: 1.15em;
}

A 500-pixel-wide chat, stuck to the right:

#chat {
  left: auto;
  width: 500px;
}

Align messages to the right edge:

.msg {
  align-self: flex-end;
  text-align: right;
}

More air between messages:

:root { --gap: 14px; }

If a rule didn't work, add !important at its end before the semicolon, for example color: red !important;.

About fonts. Only fonts already installed on the computer with OBS work. Downloading a new font and installing it in Windows takes a minute, then restart OBS.

Link and CSS together. If a parameter is given in the link (for example, size), it wins over --fs in CSS. Use one of them for each setting.
