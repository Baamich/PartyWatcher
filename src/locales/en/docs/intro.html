Docs

This is a guide for streamers. It explains in plain words what to click and what to paste. No special knowledge needed: just follow the steps from top to bottom.

How to use it

  • On the right is the list of chapters. Click a chapter to open its first page.
  • Dark code blocks are what you need to copy. There is a “Copy” button in the corner of each block.
  • Bold marks the names of buttons and windows you will see on the site or in a program.
  • At the bottom of each page there is a “Next →” button.

Chapters

  1. Streaming. First you need to go live. Without a stream there is no point in setting up the chat.
  2. Chat. How to show the chat on stream, how to make a bot with commands like !roulette, how to style the chat your way and how all of it is protected.
  3. Builder. Set up the chat look and create your own commands right on the site, without code.
  4. Profile editor. Banner, avatar, description, and in PRO mode also free placement of blocks, text, buttons and the live page layout.
  5. Presets. Ready-made chat styles and commands from other streamers: added in one click. You can publish your own too.

Words you will meet here

WordWhat it is
OBSA free program you stream with.
Stream keyThe password for your stream. It tells the site that the stream comes from you. Never show it to anyone.
Chat keyAnother password, for the chat. With it OBS shows the chat and a bot can write to the chat. Also a secret.
APIA “door” through which one program talks to the site. You don't need to understand how it works, just paste the key.
BotA small program that reads the chat and replies to commands.
Browser Source (“Browser” in OBS)A box in OBS that shows a web page. We show the chat in it.

The docs will grow. New chapters will appear in the list on the right, and old pages won't get lost.

Where to start

  • Not live yet: Streaming from OBS.
  • You're live and need the chat on stream: Chat in OBS.
  • You want a bot with commands: C# bot.
  • You want a nice-looking chat: Chat builder (no code) or Chat styling (by hand).
  • You need your own commands without programming: Chat commands.
  • You want a nice profile: Standard editor or Pro editor.
  • You don't want to set up the chat from scratch: Chat styles and Commands from presets.
