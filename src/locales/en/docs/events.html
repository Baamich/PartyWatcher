Events and OBS alerts

When something happens on your channel — a follow, a raid, a reward purchase — an animation with text and sound pops up on stream. Everything is set up in the studio under 🔔 Events, no code needed.

How to connect OBS

  1. Open the studio → 🔔 Events.
  2. At the top click 📋 Link for OBS. If there is no key yet, it is created automatically. The link is copied.
  3. In OBS: Sources → ＋ → Browser. Paste the link into “URL”, width 1920, height 1080.
  4. Tick “Control audio via OBS” so alert sounds go to the stream.
  5. Click Test on any card — the alert shows up in OBS and right on the page.

The link with the key works like a password: don't show it on stream. If it leaked, click 🔄 New key and paste the new link into OBS. The old one stops working.

Turn an event on

On the right is the list of events. The checkbox turns an event on: it gets a card and starts showing in OBS. Untick it or click × on the card to turn it off.

Event card

  • Animation. The green ⟳ button in the preview corner opens the picker: 20 built-in animations or your own GIF (up to 3 MB). The selected one is previewed at the top.
  • 🔊 Sound. 20 built-in sounds (▶ to listen), “No sound” or your own mp3/ogg/wav file up to 1 MB. Volume is there too.
  • ✏️ Text. Your own text with variables: click {name} and the like to insert them. Variables are highlighted on stream. You can pick the text color, the highlight color and one of 14 text animations. “Default” brings back the standard text (shown in the OBS language).
  • Voice. Ticked — the text is also read aloud by the system voice (in OBS on Windows — Microsoft voices). Off by default.
  • Display time — 3 to 10 seconds. A larger or smaller value is corrected automatically.
  • Test — show the event in OBS with sample data.

Everything saves by itself — there is no “Save” button. Cards can be dragged by the title and resized by the corner, like studio windows. ↺ Default at the top puts them back.

Alerts are queued: the next one appears after the previous one has faded out.

Not working?

  • Nothing shows in OBS — check that the whole link is pasted (with ?key=…) and the event is ticked.
  • “The key is wrong” in the OBS corner — the key was changed. Copy the link again.
  • No sound — turn on “Control audio via OBS” in the source properties and check the volume in the card.
