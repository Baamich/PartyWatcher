C# bot

We'll make a bot: it reads the chat, sees commands (for example, !roulette 30) and replies in the chat. Step by step, starting from zero.

What you'll get

  • A viewer types !top, and the bot replies with a list.
  • A viewer types !roulette 30, the bot writes “spinning the roulette”, waits 5 seconds and names a number from 1 to 30.

To add your own commands, just copy a ready piece of code (below).

Step 0. What to install

  1. .NET SDK (version 8 or newer). Free download: dotnet.microsoft.com/download. Click the big .NET SDK button and install it like a regular program.
  2. Check: open a Terminal (on Windows press Win+R, type cmd, Enter) and type: 
    dotnet --version
    It should show a number, for example 8.0.404. If it says “command not found”, restart the computer and try again.

Step 1. Get a chat key

Do steps 1 and 2 from Chat in OBS. The key starts with pwc_. You can copy it in full with the 📋 button next to the key field in the “Chat API” block.

Step 2. Create the bot project

In the same terminal type these commands one by one, pressing Enter after each:

mkdir ChatBot
cd ChatBot
dotnet new console
dotnet add package SocketIOClient

What this means: we created a ChatBot folder, went into it, created an empty program and added a piece that can listen to the chat. The ChatBot folder appears where the terminal is open (on Windows usually C:\Users\YourName).

Step 3. Paste the bot code

  1. Open the ChatBot folder and find the Program.cs file in it.
  2. Open it with any editor (even Notepad will do).
  3. Delete everything in it.
  4. Paste the code below (the “Copy” button in the corner of the block).
  5. Find the line with ApiKey and replace pwc_PUT_YOUR_KEY_HERE with your key. Keep the " quotes around the key.
  6. Save the file (Ctrl+S).
// ===== 1. Include the needed "pieces" =====
using System.Collections.Concurrent;
using System.Net.Http.Headers;
using System.Net.Http.Json;
using System.Text.Json.Serialization;
using SocketIOClient;

// ===== 2. SETTINGS. Only ApiKey needs to be changed =====
const string BaseUrl = "https://partywatcher.de";      // site address, don't touch
const string ApiKey  = "pwc_PUT_YOUR_KEY_HERE";        // your chat key, inside the quotes

// ===== 3. This is how the bot SENDS messages to the chat =====
using var http = new HttpClient { BaseAddress = new Uri(BaseUrl) };
http.DefaultRequestHeaders.Authorization = new AuthenticationHeaderValue("Bearer", ApiKey);

// ===== 4. Memory for the roulette: who started it and when (so nobody spams) =====
var cooldowns = new ConcurrentDictionary<string, DateTime>();

// ===== 5. This is how the bot LISTENS to the chat =====
var client = new SocketIO(new Uri(BaseUrl + "/chat"));

// Once connected, tell the site: "I'm the bot of this channel".
// If the connection drops, the bot reconnects and comes here again.
client.OnConnected += async (_, _) =>
{
    Console.WriteLine("Connected to the chat. Waiting for commands...");
    await client.EmitAsync("chat:join", new object[] { new { chatKey = ApiKey } });
};

client.OnDisconnected += (_, reason) => Console.WriteLine("Connection lost: " + reason);

// ===== 6. EVERY new chat message arrives here =====
client.On("chat:message", async response =>
{
    try
    {
        var msg = response.GetValue<ChatMessage>(0);

        // Skip our own messages, otherwise the bot will start replying to itself.
        if (msg.External && msg.Source == "bot") return;

        var text = msg.Text.Trim();   // message text without spaces at the edges

        // ---------- EXAMPLE 1 and 2: the !top command ----------
        // Example 1: the bot SEES the command (writes to the black window on your computer).
        // Example 2: the bot REPLIES in the chat.
        if (text.Equals("!top", StringComparison.OrdinalIgnoreCase))
        {
            Console.WriteLine($"{msg.SenderUsername} wrote !top");
            await SendAsync("🏆 Top viewers: 1) Alex  2) Sam  3) Max");
            return;
        }

        // ---------- EXAMPLE 3: the !roulette 30 command ----------
        // Split the message into words: "!roulette" and "30".
        var parts = text.Split(' ', StringSplitOptions.RemoveEmptyEntries);

        if (parts.Length == 2
            && parts[0].Equals("!roulette", StringComparison.OrdinalIgnoreCase)
            && int.TryParse(parts[1], out var max)     // the second word must be a number
            && max >= 2 && max <= 1_000_000)           // and a reasonable one
        {
            // No more often than once in 15 seconds per person.
            var now = DateTime.UtcNow;
            if (cooldowns.TryGetValue(msg.SenderUsername, out var last)
                && now - last < TimeSpan.FromSeconds(15)) return;
            cooldowns[msg.SenderUsername] = now;

            var who = msg.SenderUsername;
            await SendAsync($"🎲 {who} spins the roulette 1–{max}… result in 5 seconds!");

            // Wait 5 seconds "on the side" so the bot doesn't freeze and keeps reading the chat.
            _ = Task.Run(async () =>
            {
                await Task.Delay(TimeSpan.FromSeconds(5));
                var n = Random.Shared.Next(1, max + 1);   // random number from 1 to max
                await SendAsync($"🎲 {who}, rolled {n} (out of {max})");
            });
        }
    }
    catch (Exception ex)
    {
        Console.WriteLine("Error: " + ex.Message);
    }
});

// ===== 7. Start and keep running =====
await client.ConnectAsync();
await Task.Delay(Timeout.Infinite);

// ===== 8. The "write to chat" function =====
async Task SendAsync(string text, string username = "Bot")
{
    var resp = await http.PostAsJsonAsync("/api/chat/send", new { text, username, source = "bot" });
    if (!resp.IsSuccessStatusCode)
        Console.WriteLine($"Not sent ({(int)resp.StatusCode}): {await resp.Content.ReadAsStringAsync()}");
}

// ===== 9. What a message from the site looks like =====
class ChatMessage
{
    [JsonPropertyName("senderUsername")] public string SenderUsername { get; set; } = "";
    [JsonPropertyName("text")]           public string Text { get; set; } = "";
    [JsonPropertyName("isOwner")]        public bool IsOwner { get; set; }
    [JsonPropertyName("external")]       public bool External { get; set; }
    [JsonPropertyName("source")]         public string? Source { get; set; }
}

Step 4. Run the bot

  1. In the terminal (it must be in the ChatBot folder) type: 
    dotnet run
  2. Wait a few seconds. The line “Connected to the chat. Waiting for commands...” should appear. That means everything works.
  3. Don't close the terminal window: the bot works while it's open. To stop the bot, press Ctrl+C in it.

Step 5. Check it

  1. Open your chat, for example https://partywatcher.de/streamers/baamich.
  2. Type !top. The bot should reply with a list.
  3. Type !roulette 30. The bot writes “spins the roulette”, and after 5 seconds names a number from 1 to 30.

How to add your own command

Copy this piece and paste it into the code right below the line var text = msg.Text.Trim(); (above “EXAMPLE 1 and 2”):

if (text.Equals("!hello", StringComparison.OrdinalIgnoreCase))
{
    await SendAsync($"Hello, {msg.SenderUsername}! 👋");
    return;
}

What to change: !hello to your command, and the text in SendAsync(...) to your reply. {msg.SenderUsername} inserts the name of whoever wrote it. After changes, stop the bot (Ctrl+C) and run it again (dotnet run).

Not working?

What you seeWhat to do
dotnet not foundInstall the .NET SDK (step 0) and restart the computer.
The bot doesn't print “Connected to the chat”Check the internet and that BaseUrl is exactly https://partywatcher.de. If it is, check the package version: in the bot folder type dotnet add package SocketIOClient to update it.
“Not sent (401)”The key is wrong. Copy it again from the studio (📋) and paste it between the quotes, without spaces.
“Not sent (429)”The bot writes too often. Wait a few seconds.
The bot is connected but ignores commandsThe command must be written exactly: !top, with no extra words. Restart the bot after editing the code.
