API reference

All chat requests and events in one place. This page is for those who write a bot or a bridge themselves. If you just show the chat in OBS, you don't need it.

How to send a message to the chat

Send a POST request to:

https://partywatcher.de/api/chat/send

Put the chat key in the headers: Authorization: Bearer pwc_... (or X-Api-Key: pwc_...). Don't put the key in the URL: it would end up in logs.

Body field (JSON)What it is
textMessage text. Required, up to 500 characters.
usernameSender name, up to 32 characters. If omitted, it will be “Bot”.
sourceA label for where the message comes from: Latin letters, digits, _ and -, up to 16 characters. For example twitch, vk, bot. If omitted, it will be api.
colorNickname color as #rrggbb, for example #9146ff. Optional.

Terminal example (replace the key with yours):

curl -X POST https://partywatcher.de/api/chat/send \
  -H "Authorization: Bearer pwc_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"text":"hello from twitch","username":"viewer123","source":"twitch","color":"#9146ff"}'

What the site responds

CodeWhat it means
200All good, the message is in the chat.
400The message is empty.
401The key is missing or wrong.
429Too often. The response has Retry-After: in how many seconds you can try again.
500An error on the site side. Try later.

How to read the chat

Connect via Socket.IO to https://partywatcher.de/chat. Right after connecting, send the chat:join event with the body { "chatKey": "your key" }. Such a connection is read-only and doesn't appear in the viewer list.

EventWhen it arrives
chat:historyRight after joining: up to 50 latest messages.
chat:messageA new message appeared (from a viewer or via the API).
chat:message-deletedA message was deleted. The event has messageId.
chat:clearedThe chat was cleared.
chat:overlay-errorThe key is wrong. The event has error.

What's inside a message

FieldWhat it is
_idMessage id.
senderUsernameSender name.
textText.
isOwnertrue if the channel owner writes.
externaltrue if the message came via the API (from a bot or a bridge).

senderIdSite user id. For messages via the API it is null.
