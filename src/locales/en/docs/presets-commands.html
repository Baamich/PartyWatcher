Commands

A command preset is a ready-made command like !random 30 from another streamer. You can add it in one click without coming up with a reply.

How to add someone's command

  1. Open 🎨 Presets and choose the Commands filter.
  2. The card shows how it works: Input (what the viewer writes) and Output (what the bot replies).
  3. Click ＋ Add. The command appears in Chat commands.
  4. If you already have a command with that name, the site will suggest another name.

An added command can be edited and turned off like a regular one.

How to publish your command

  1. Create a command in the Builder, the 🤖 Commands section.
  2. Click 📤 Publish preset next to “＋ Create” (or ＋ Publish preset on the presets page).
  3. Choose the command from the list, enter a name (required) and a description (optional).
  4. Click Publish.

The current version of the command is published. If you change it later, the preset keeps what it was at publishing. To update it, delete the preset and publish again.

Remove and delete

  • The trash can on the card deletes your preset (after confirmation). Commands others already added stay with them.
  • Remove an added command. Click “✓ Added” or the trash can on someone else's preset. The command is also deleted from your commands, a dialog warns about it.
  • If you deleted an added command manually in the Builder, the preset still stays in your added list. Click the trash can to remove it and restore the counter.

Good to know

  • The limits are the same as for regular commands: up to 50 commands per channel.
  • Read the reply before adding: the bot will write it to your chat under its own name.
  • Likes: one per account, for accounts older than one day. You can't like your own preset.
