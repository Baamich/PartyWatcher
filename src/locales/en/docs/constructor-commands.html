Chat commands

Your own commands like !rules or !random 30: a viewer types a command, the bot replies in the chat. No coding needed.

How to create a command

  1. Open 🧩 Builder and choose 🤖 Commands on the right.
  2. Click “＋ Create”. At the top there are quick templates (Random, Dice, Coin and others): click any of them and everything is filled in.
  3. In the Command field write the name without the exclamation mark, for example rules (letters, digits and _, up to 20 characters).
  4. In the What the bot replies field write the text (up to 400 characters). The variable buttons insert variables into the text.
  5. At the bottom of the window you can see how the reply will look. You can change the “what the viewer writes” field to test different cases.
  6. Click “Create”.

Arguments: commands with a parameter

An argument is a word the viewer writes after the command. For example, in !random 30 the “number” argument equals 30.

  1. In the command window, in the Arguments block, write a name, for example number, and click “＋ Add”. The “optional” checkbox lets the viewer skip this argument.
  2. Use the name in curly braces in the reply: {number}.
Command:   random
Argument:  number
Reply:     Random number up to {number}: {random:{number}}

A viewer types !random 30, the bot replies: “Random number up to 30: 21”. If the viewer forgot the number, the bot hints: “Usage: !random <number>”. Up to 5 arguments are allowed.

Variables

VariableWhat gets inserted
{user}Nickname of whoever used the command
{streamer}Your channel name
{title}Stream title
{viewers}How many people are in the chat now
{uptime}How long the stream has been live (or “offline”)
{count}How many times this command has been used
{args}Everything the viewer wrote after the command
{arg1}, {arg2}, …The first, second word after the command
{target}The first word after the command without @ (if there is none, the author's nickname)
{number} (your own name)The value of your argument
{random}A random number from 1 to 100
{random:30}, {random:5-10}A random number from 1 to 30, from 5 to 10
{dice}Dice: a number from 1 to 6
{coin}“heads” or “tails” (in the language of whoever used the command)
{choice:yes|no|maybe}A random option from a list (separated by |)
{calc:2+2*3}Calculator: + - * / % and parentheses
{time}, {date}Moscow time and date. Another time zone — an offset from UTC (−14 to +14): {time:+1} — Germany in winter, {time:+2} — in summer, {time:+3} — Moscow
{followers}, {category}Channel followers and the stream category (game)
{followage}How long the sender has followed the channel: “41 d 3 h”
{points}, {points_name}The sender's channel points balance and the name of the points
{account_age}, {messages}Age of the sender's account and how many messages they left in the channel chat in 3 days
{random_user}A random viewer currently on the channel page (for giveaways)
{last_follower}The channel's latest follower
{weekday}Day of the week, Moscow time (or shifted: {weekday:+2})
{countdown:2026-12-31 20:00}Time left until a date (Moscow time): “72 d 10 h”
{upper:…}, {lower:…}Text in UPPERCASE or lowercase: {upper:{user}}
{widget:name}Number or text of an OBS widget by its command name: {widget:deaths} — how many times the streamer died

Variables can be nested: {random:{number}}, {calc:{args}}.

Examples

!dice       →  🎲 {user} rolled the dice: {random:6}
!hug        →  {user} hugs {whom} 🤗              (argument “whom”)
!calc       →  {args} = {calc:{args}}            (argument “expression”)
!time       →  It's {time:+3} in Moscow, {date:+3}

Command table

All commands are shown in a table: on the left a pencil (edit), then the name with arguments, the reply, how many times it was used, a toggle and on the right a trash can (delete). The toggle turns the command on and off: green means the bot replies, light means the command is off but not deleted.

Good to know

  • The bot replies as Bot with the BOT label.
  • The bot repeats one command no more often than once every 3 seconds, so it doesn't flood the chat.
  • You can create up to 50 commands.
  • Commands work when a viewer writes right on the site. Messages that come via the API (for example, a bridge from Twitch) don't trigger commands.
  • Curly braces are removed from what the viewer writes in arguments, so nobody can inject their own variables into someone else's reply.

If you have your own C# bot (C# bot) and it replies to the same command, the reply will come twice. Pick one.
