Chat in OBS

We'll show the chat right on your stream. Viewers will see messages on screen, and you won't have to switch to the site.

What you need beforehand

  • You have already gone live following the guide (or at least set up OBS).

Step 1. Open “Chat API”

  1. Open the studio: https://partywatcher.de/workbench.html.
  2. On the right find the “Chat” window. Above the messages there is a thin bar with an arrow ▲ Chat API. Click it.
  3. The bar expands and the chat window gets taller. Inside there is a field and buttons.

Step 2. Create a chat key

  1. Click “🔄 Generate”. Something like ****a1b2 appears in the field: that's the hidden key, only its end is visible.
  2. You don't need to copy anything else, just use the link button next.

Step 3. Copy the OBS link

Click “OBS link (Browser Source) 📋”. That's it, the link is in your clipboard. It looks like this (the key inside is not shown):

https://partywatcher.de/overlay/chat.html#key=pwc_...

Step 4. Add the chat to OBS

  1. In OBS find the Sources panel at the bottom and click “+”.
  2. Choose Browser in the list.
  3. Choose “Create new”, name it, for example, Chat, click OK.
  4. In the window that opens, paste the link into the URL field (Ctrl+V).
  5. Width: 400, Height: 700. (You can resize it with the mouse later.)
  6. Find the “Shutdown source when not visible” checkbox and uncheck it. Otherwise the chat will miss messages when you switch scenes.
  7. Click OK.

Step 5. Put the chat where you want

The chat appears on the scene as an invisible frame. Drag it to the corner you want, and use the red dots on the edges to stretch or shrink it.

Check it

  1. Open your profile in the browser, for example https://partywatcher.de/streamers/(your name).
  2. Write any message in the chat.
  3. The message should appear in OBS. Your nickname will have a red plate.

Simple settings via the link

You can append parameters to the end of the link. Each starts with &:

AppendWhat happens
&size=30Bigger text (a number from 10 to 80)
&fade=40A message disappears after 40 seconds
&max=15No more than 15 messages on screen

Example: https://partywatcher.de/overlay/chat.html#key=pwc_...&size=30&fade=40

More settings (colors, font, background) are in the Chat styling chapter.

Not working?

What you seeWhat to do
“The link has no key”You pasted the link without #key=.... Copy it again with the button in the studio.
“Invalid chat key”The key was regenerated. Copy the new link and paste it into the source (right-click the source → Properties → URL).
The chat is emptyNobody has written anything yet. Write something yourself. If it doesn't appear, click “Refresh cache of current page” in the source.

The link contains the chat key. Don't show it on stream (for example, when opening the source properties) and don't send it to anyone. More: Security and limits.
