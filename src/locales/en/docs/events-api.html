Events API

For those writing their own bot: all channel events arrive in real time over Socket.IO. The key is the same as in the OBS link (studio → 🔔 Events).

Connecting

Connect over Socket.IO to https://partywatcher.de/alerts and right away send alerts:join with the key:

const { io } = require('socket.io-client');
const socket = io('https://partywatcher.de/alerts');
socket.on('connect', () => socket.emit('alerts:join', { key: 'YOUR_KEY' }));
socket.on('alerts:ready', ({ channel }) => console.log('connected to', channel));
socket.on('alerts:error', () => console.log('wrong key'));
socket.on('event', (e) => console.log(e.type, e.vars));

What arrives

Socket eventWhat it is
event{ type, vars, at } — every channel event, even ones turned off in the studio. type is one of the types below, vars are the same variables as in the text.
alertWhat the OBS overlay shows (only events that are on, and “Test”): animation, sound and text settings.
alerts:ready / alerts:errorThe key was accepted / is wrong. After 5 failed tries the socket is disconnected.
