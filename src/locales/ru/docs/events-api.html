API событий

Для тех, кто пишет своего бота: все события канала приходят в реальном времени по Socket.IO. Ключ — тот же, что у ссылки для OBS (студия → 🔔 События).

Подключение

Подключись по Socket.IO к адресу https://partywatcher.de/alerts и сразу отправь alerts:join с ключом:

const { io } = require('socket.io-client');
const socket = io('https://partywatcher.de/alerts');
socket.on('connect', () => socket.emit('alerts:join', { key: 'ТВОЙ_КЛЮЧ' }));
socket.on('alerts:ready', ({ channel }) => console.log('подключено к', channel));
socket.on('alerts:error', () => console.log('ключ не подходит'));
socket.on('event', (e) => console.log(e.type, e.vars));

Что приходит

Событие сокетаЧто это
event{ type, vars, at } — каждое событие канала, даже выключенное в студии. type — один из типов ниже, vars — те же переменные, что в надписи.
alertЧто показывает оверлей OBS (только включённые события и «Проверить»): настройки анимации, звука и надписи.
alerts:ready / alerts:errorКлюч принят / не подходит. После 5 неудачных попыток сокет отключается.
