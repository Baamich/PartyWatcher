Подключить свой бот или чат Twitch / VK

У тебя уже есть бот, который читает чат Twitch или VK? Его не нужно переписывать: достаточно, чтобы он пересылал сообщения на наш сайт одним HTTP-запросом. Тогда в чате канала и в OBS будут сообщения со всех площадок сразу, с меткой, откуда они пришли.

Как это устроено

  • Чужой чат → наш. Бот получает сообщение на Twitch или VK и делает POST https://partywatcher.de/api/chat/send с ключом чата. Сообщение появляется у нас с меткой источника (twitch, vk…) и цветом ника.
  • Наш чат → чужой (по желанию). Бот подключается к нашему чату по Socket.IO с тем же ключом и пересылает новые сообщения на Twitch или VK от имени своего аккаунта.
  • Ключ чата — в студии: «Управление трансляцией» → «API чата» (подробно — Чат в OBS, шаги 1–2). Это не ключ трансляции и не ключ событий.

Если в боте есть шаг «HTTP-запрос» или «Webhook»

Многие готовые боты и программы умеют отправлять запрос без кода. Настрой его так:

ПолеЗначение
МетодPOST
Адрес (URL)https://partywatcher.de/api/chat/send
ЗаголовокAuthorization: Bearer pwc_… (твой ключ чата)
ЗаголовокContent-Type: application/json
Тело{"text": "текст сообщения", "username": "ник", "source": "twitch", "color": "#9146ff"}

Вместо текста и ника подставь переменные своего бота (обычно что-то вроде %message% и %user%). source — латиница до 16 символов: twitch, vk, youtube, kick — что угодно. color необязателен.

Пример: Twitch → наш чат на Node.js

Самый короткий мост: читает чат Twitch без входа в аккаунт (анонимно) и пересылает каждое сообщение к нам. Нужен Node.js 18+ и одна библиотека:

npm install tmi.js
// twitch-bridge.js — запуск: PW_KEY=pwc_... TWITCH_CHANNEL=имя node twitch-bridge.js
const tmi = require('tmi.js');

const KEY = process.env.PW_KEY;            // ключ чата PartyWatcher — не пиши его прямо в код
const client = new tmi.Client({ channels: [process.env.TWITCH_CHANNEL] });

client.on('message', async (channel, tags, message) => {
  try {
    const res = await fetch('https://partywatcher.de/api/chat/send', {
      method: 'POST',
      headers: { Authorization: 'Bearer ' + KEY, 'Content-Type': 'application/json' },
      body: JSON.stringify({
        text: message,
        username: tags['display-name'] || tags.username,
        source: 'twitch',
        color: tags.color || '#9146ff',
      }),
    });
    if (res.status === 429) console.warn('Слишком часто, сайт просит подождать', res.headers.get('retry-after'), 'с');
  } catch (e) {
    console.warn('Не отправилось:', e.message);
  }
});

client.connect();

Пример: любой бот на Python

Если бот уже написан на Python (для VK, Twitch или чего-то ещё), добавь в него одну функцию и вызывай её на каждое новое сообщение:

import os, requests

PW_KEY = os.environ["PW_KEY"]  # ключ чата PartyWatcher

def to_partywatcher(user, text, source="vk", color=None):
    body = {"text": text[:500], "username": user[:32], "source": source}
    if color:
        body["color"] = color
    try:
        r = requests.post("https://partywatcher.de/api/chat/send",
                          json=body, headers={"Authorization": "Bearer " + PW_KEY}, timeout=5)
        if r.status_code == 429:
            print("Слишком часто, подождать", r.headers.get("Retry-After"), "с")
    except requests.RequestException as e:
        print("Не отправилось:", e)

# в обработчике новых сообщений своего бота:
# to_partywatcher(author_name, message_text, source="vk", color="#0077ff")

Обратно: наш чат → Twitch или VK

Подключись к нашему чату с тем же ключом и пересылай новые сообщения. Важно: пропускай сообщения с external: true — это то, что твой же бот прислал с Twitch или VK. Иначе сообщения будут ходить по кругу.

npm install socket.io-client
const { io } = require('socket.io-client');

const pw = io('https://partywatcher.de/chat', { transports: ['websocket', 'polling'] });
pw.on('connect', () => pw.emit('chat:join', { chatKey: process.env.PW_KEY }));
pw.on('chat:overlay-error', (e) => console.error('Ключ не подошёл:', e.error));

pw.on('chat:message', (m) => {
  if (m.external) return;                  // пришло с Twitch/VK или от бота — не отправляем обратно
  const text = m.masked || m.text;         // с маской фильтра слов канала
  sendToTwitch(`[PW] ${m.senderUsername}: ${text}`); // твоя функция отправки на площадку
});

Чтобы писать в чат Twitch, боту нужен свой аккаунт Twitch и токен — это настраивается на стороне Twitch, не у нас. Для VK — так же, через API самого VK.

Команды, награды и события для бота

  • Команды !команда из «Конструктора» отвечают только на сообщения, написанные в нашем чате. На Twitch и VK команды пусть обрабатывает твой бот. Ответы нашего бота приходят с source: "bot" — их можно переслать на Twitch, если хочешь.
  • События канала (подписка, рейд, покупка награды) — по ключу событий, см. API событий. Например, бот может написать на Twitch «Спасибо за подписку на PartyWatcher!».
  • Покупки наград и отметка «выполнено / вернуть поинты» — API наград.
  • Виджеты OBS бот может двигать командами чата /timer, /count и т. д. только от аккаунта стримера или модератора — через API ключа чата команды модерации не выполняются.

Лимиты и безопасность

  • Не больше 20 сообщений за 10 секунд и 100 в минуту на канал. Сверх лимита — ответ 429 и заголовок Retry-After. В очень активном чате пересылай не всё (например, без сообщений из одних смайлов).
  • Текст — до 500 символов, ник — до 32. Сообщения через API помечаются external, и в OBS у них видна метка источника.
  • Ключ храни в переменной окружения или файле настроек, не в коде и не на стриме. Утёк — создай новый в «API чата», старый сразу перестанет работать. Подробнее — Безопасность и лимиты.

Не работает?

  • 401 — ключ неверный или старый. Проверь, что в заголовке Bearer pwc_… с пробелом после Bearer.
  • 400 — пустой text: бот передал не то поле.
  • Сообщения приходят дважды — бот запущен два раза или пересылает обратно свои же сообщения (смотри external).
