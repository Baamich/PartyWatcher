Безопасность

Сменить почту и пароль или удалить аккаунт можно только с главного устройства — так никто с украденным паролем не выкинет тебя из аккаунта. Забыл пароль — «Забыли пароль?» на странице входа. Потерял главное устройство — напиши в поддержку.

Смена почты

На новую почту придёт письмо со ссылкой. Пока по ней не перейдёшь, почта аккаунта прежняя.

Смена пароля

  • Минимум 8 символов
  • Первая буква — заглавная латиница (A–Z)
  • Есть буквы
  • Есть цифры
  • Пароли совпадают

Удаление аккаунта

  • Сразу после запроса ты выйдешь на всех устройствах, ключ эфира и ключ API чата перестанут работать.
  • Через 3 дня аккаунт удалится насовсем: комнаты, канал, клипы, записи эфиров, награды, смайлы, пре-сеты, подписки. Поддержка может удалить его и раньше.
  • Твои сообщения в чужих чатах эфиров останутся, но без ника — «Удалённый пользователь».
  • Передумал — просто войди с паролем в эти 3 дня, удаление отменится.
