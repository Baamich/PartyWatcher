Справочник API

Все запросы и события чата в одном месте. Эта страница нужна тем, кто пишет бота или мост сам. Если ты просто показываешь чат в OBS, она тебе не нужна.

Как отправить сообщение в чат

Отправь запрос POST на адрес:

https://partywatcher.de/api/chat/send

В заголовках укажи ключ чата: Authorization: Bearer pwc_... (или X-Api-Key: pwc_...). В адресную строку ключ не пиши: он попадёт в журналы.

Поле в теле (JSON)Что это
textТекст сообщения. Обязательно, до 500 символов.
usernameИмя отправителя, до 32 символов. Если не указать, будет «Бот».
sourceМетка, откуда сообщение: латинские буквы, цифры, _ и -, до 16 символов. Например twitch, vk, bot. Если не указать, будет api.
colorЦвет ника в виде #rrggbb, например #9146ff. Необязательно.

Пример для терминала (ключ замени на свой):

curl -X POST https://partywatcher.de/api/chat/send \
  -H "Authorization: Bearer pwc_ТВОЙ_КЛЮЧ" \
  -H "Content-Type: application/json" \
  -d '{"text":"привет из твича","username":"viewer123","source":"twitch","color":"#9146ff"}'

Что отвечает сайт

КодЧто значит
200Всё хорошо, сообщение в чате.
400Сообщение пустое.
401Ключа нет или он неверный.
429Слишком часто. В ответе есть Retry-After: через сколько секунд можно снова.
500Ошибка на стороне сайта. Попробуй позже.

Как читать чат

Подключись по Socket.IO к адресу https://partywatcher.de/chat. Сразу после подключения отправь событие chat:join с телом { "chatKey": "твой ключ" }. Такое подключение только читает и не появляется в списке зрителей.

СобытиеКогда приходит
chat:historyСразу после входа: до 50 последних сообщений.
chat:messageПоявилось новое сообщение (от зрителя или из API).
chat:message-deletedСообщение удалено. В событии есть messageId.
chat:clearedЧат очищен.
chat:overlay-errorКлюч неверный. В событии есть error.

Что внутри сообщения

ПолеЧто это
_idНомер сообщения.
senderUsernameИмя отправителя.
textТекст.
isOwnertrue, если пишет владелец канала.
externaltrue, если сообщение пришло через API (от бота или моста).
sourceМетка источника (у сообщений через API).
nickColorЦвет ника #rrggbb или null.
senderIdНомер пользователя сайта. У сообщений через API это null.
createdAtКогда отправлено.
