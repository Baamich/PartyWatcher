Стилизация чата

Как изменить вид чата в OBS: цвета, шрифт, фон, размер. Есть два способа: простой (через ссылку) и гибкий (через свой CSS).

Способ 1. Параметры в ссылке (самый простой)

Возьми ссылку для OBS (кнопка «Ссылка для OBS» в блоке «API чата») и допиши в её конец нужные параметры. Каждый параметр начинается с &. Потом вставь ссылку в источник OBS: правый клик на источнике → Свойства → поле URL.

ДопишиЧто делает
&size=30Размер текста, число от 10 до 80. Обычный: 22.
&font=ArialШрифт. Подойдёт любой шрифт, установленный на твоём компьютере. Пробелы пиши как есть: &font=Comic Sans MS.
&color=ffe066Цвет текста. 6 символов цвета без решётки.
&bg=000000Цвет фона под каждым сообщением (чёрный). Без решётки.
&bgalpha=55Насколько фон непрозрачный: 0 — невидимый, 100 — сплошной. Если указан bg, а bgalpha нет, будет 60.
&owner=7c3aedЦвет плашки на твоём нике (по умолчанию красный). Без решётки.
&shadow=0Убрать тень у текста.
&fade=40Сообщение пропадает через 40 секунд. 0 — не пропадает.
&max=15Сколько сообщений держать на экране (от 5 до 100).

Где взять цвет. Открой в браузере любой «выбор цвета» (поищи «color picker»), выбери цвет и скопируй его код вида #ffe066. В ссылку пиши без значка #: ffe066.

Пример готовой ссылки (ключ замени на свой):

https://partywatcher.de/overlay/chat.html#key=pwc_...&size=28&color=ffe066&bg=000000&bgalpha=55&owner=7c3aed&fade=40

Способ 2. Свой CSS (для тех, кто хочет больше)

CSS это «правила оформления». В OBS для них есть специальное поле.

  1. В OBS правый клик на источнике с чатом → Свойства.
  2. Найди поле Пользовательский CSS (по-английски Custom CSS). В нём уже что-то написано, не удаляй это.
  3. Допиши свои правила в конец (с новой строки).
  4. Нажми ОК. Если вид не поменялся, снова открой Свойства и нажми «Обновить кэш текущей страницы».

Из чего состоит чат (названия, которые можно менять)

НазваниеЧто это
#chatВесь список сообщений целиком
.msgОдно сообщение целиком (ник и текст)
.nickНик
.nick--ownerНик владельца канала (с плашкой)
.sepДвоеточие после ника
.textТекст сообщения
.srcМетка источника, например TWITCH или BOT

Переменные: самый простой способ в CSS

Можно поменять одну «настройку» вместо целого правила:

ПеременнаяЧто меняет
--fsРазмер текста, например 30px
--fontШрифт, например "Impact", sans-serif
--textЦвет текста
--msg-bgФон сообщения, например rgba(0, 0, 0, 0.5)
--owner-bgЦвет плашки ника владельца
--text-shadowТень текста (none — без тени)
--gapРасстояние между сообщениями, например 12px
:root {
  --fs: 30px;
  --text: #ffe066;
  --msg-bg: rgba(0, 0, 0, 0.5);
}

Готовые рецепты (копируй и вставляй)

Тёмные «плашки» под сообщениями:

.msg {
  background: rgba(0, 0, 0, 0.55);
  border-radius: 12px;
  padding: 4px 12px;
}

Убрать метки TWITCH / BOT:

.src { display: none; }

Показывать только текст, без ников:

.nick, .sep { display: none; }

Ник крупнее и цветной:

.nick {
  color: #ffd166 !important;
  font-size: 1.15em;
}

Чат шириной 500 пикселей, прижатый вправо:

#chat {
  left: auto;
  width: 500px;
}

Сообщения прижать к правому краю:

.msg {
  align-self: flex-end;
  text-align: right;
}

Больше воздуха между сообщениями:

:root { --gap: 14px; }

Если правило не сработало, допиши в его конце !important перед точкой с запятой, например color: red !important;.

Про шрифты. Работают только те шрифты, которые уже стоят на компьютере с OBS. Скачать новый шрифт и поставить его в Windows можно за минуту, после этого перезапусти OBS.

Ссылка и CSS вместе. Если параметр указан в ссылке (например, size), он сильнее, чем --fs в CSS. Используй что-то одно для каждой настройки.
