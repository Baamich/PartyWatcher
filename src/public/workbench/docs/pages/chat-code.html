Бот на C#

Мы сделаем бота: он читает чат, видит команды (например, !рулетка 30) и отвечает в чат. Пошагово, начиная с нуля.

Что получится

  • Зритель пишет !топы, и бот отвечает списком.
  • Зритель пишет !рулетка 30, бот пишет «запускаю рулетку», ждёт 5 секунд и называет число от 1 до 30.

Чтобы добавить свои команды, достаточно скопировать готовый кусок кода (есть ниже).

Шаг 0. Что нужно установить

  1. .NET SDK (версия 8 или новее). Скачать бесплатно: dotnet.microsoft.com/download. Нажми большую кнопку .NET SDK и поставь программу, как обычную.
  2. Проверка: открой Терминал (на Windows нажми Win+R, напиши cmd, Enter) и напиши: 
    dotnet --version
    Должно показать число, например 8.0.404. Если пишет «команда не найдена», перезагрузи компьютер и попробуй ещё раз.

Шаг 1. Получи ключ чата

Сделай шаги 1 и 2 из Чат в OBS. Ключ начинается с pwc_. Скопировать его целиком можно кнопкой 📋 рядом с полем ключа в блоке «API чата».

Шаг 2. Создай проект бота

В том же терминале напиши эти команды по одной, после каждой нажимай Enter:

mkdir ChatBot
cd ChatBot
dotnet new console
dotnet add package SocketIOClient

Что это значит: создали папку ChatBot, зашли в неё, создали пустую программу и добавили кусочек, который умеет слушать чат. Папка ChatBot появится там, где открыт терминал (на Windows обычно C:\Users\ТвоёИмя).

Шаг 3. Вставь код бота

  1. Открой папку ChatBot и найди в ней файл Program.cs.
  2. Открой его любым редактором (подойдёт даже Блокнот).
  3. Удали всё, что там написано.
  4. Вставь код ниже (кнопка «Копировать» в углу блока).
  5. Найди строку с ApiKey и замени pwc_СЮДА_ВСТАВЬ_СВОЙ_КЛЮЧ на свой ключ. Кавычки " вокруг ключа оставь на месте.
  6. Сохрани файл (Ctrl+S).
// ===== 1. Подключаем нужные «кусочки» =====
using System.Collections.Concurrent;
using System.Net.Http.Headers;
using System.Net.Http.Json;
using System.Text.Json.Serialization;
using SocketIOClient;

// ===== 2. НАСТРОЙКИ. Менять нужно только ApiKey =====
const string BaseUrl = "https://partywatcher.de";      // адрес сайта, не трогай
const string ApiKey  = "pwc_СЮДА_ВСТАВЬ_СВОЙ_КЛЮЧ";   // твой ключ чата, внутри кавычек

// ===== 3. Через это бот ОТПРАВЛЯЕТ сообщения в чат =====
using var http = new HttpClient { BaseAddress = new Uri(BaseUrl) };
http.DefaultRequestHeaders.Authorization = new AuthenticationHeaderValue("Bearer", ApiKey);

// ===== 4. Память для рулетки: кто и когда её запускал (чтобы не спамили) =====
var cooldowns = new ConcurrentDictionary<string, DateTime>();

// ===== 5. Через это бот СЛУШАЕТ чат =====
var client = new SocketIO(new Uri(BaseUrl + "/chat"));

// Когда подключились, говорим сайту: «я бот этого канала».
// Если связь пропадёт, бот сам переподключится и снова сюда зайдёт.
client.OnConnected += async (_, _) =>
{
    Console.WriteLine("Подключён к чату. Жду команды...");
    await client.EmitAsync("chat:join", new object[] { new { chatKey = ApiKey } });
};

client.OnDisconnected += (_, reason) => Console.WriteLine("Связь пропала: " + reason);

// ===== 6. Сюда прилетает КАЖДОЕ новое сообщение из чата =====
client.On("chat:message", async response =>
{
    try
    {
        var msg = response.GetValue<ChatMessage>(0);

        // Свои же сообщения не читаем, иначе бот начнёт отвечать сам себе.
        if (msg.External && msg.Source == "bot") return;

        var text = msg.Text.Trim();   // текст сообщения без пробелов по краям

        // ---------- ПРИМЕР 1 и 2: команда !топы ----------
        // Пример 1: бот ВИДИТ команду (пишет в чёрное окно на твоём компьютере).
        // Пример 2: бот ОТВЕЧАЕТ в чат.
        if (text.Equals("!топы", StringComparison.OrdinalIgnoreCase))
        {
            Console.WriteLine($"{msg.SenderUsername} написал !топы");
            await SendAsync("🏆 Топ зрителей: 1) Вася  2) Петя  3) Коля");
            return;
        }

        // ---------- ПРИМЕР 3: команда !рулетка 30 ----------
        // Режем сообщение на слова: "!рулетка" и "30".
        var parts = text.Split(' ', StringSplitOptions.RemoveEmptyEntries);

        if (parts.Length == 2
            && parts[0].Equals("!рулетка", StringComparison.OrdinalIgnoreCase)
            && int.TryParse(parts[1], out var max)     // второе слово должно быть числом
            && max >= 2 && max <= 1_000_000)           // и разумным
        {
            // Не чаще раза в 15 секунд от одного человека.
            var now = DateTime.UtcNow;
            if (cooldowns.TryGetValue(msg.SenderUsername, out var last)
                && now - last < TimeSpan.FromSeconds(15)) return;
            cooldowns[msg.SenderUsername] = now;

            var who = msg.SenderUsername;
            await SendAsync($"🎲 {who} запускает рулетку 1–{max}… результат через 5 секунд!");

            // Ждём 5 секунд «в сторонке», чтобы бот не завис и читал остальной чат.
            _ = Task.Run(async () =>
            {
                await Task.Delay(TimeSpan.FromSeconds(5));
                var n = Random.Shared.Next(1, max + 1);   // случайное число от 1 до max
                await SendAsync($"🎲 {who}, выпало {n} (из {max})");
            });
        }
    }
    catch (Exception ex)
    {
        Console.WriteLine("Ошибка: " + ex.Message);
    }
});

// ===== 7. Запускаем и не выключаемся =====
await client.ConnectAsync();
await Task.Delay(Timeout.Infinite);

// ===== 8. Функция «написать в чат» =====
async Task SendAsync(string text, string username = "Бот")
{
    var resp = await http.PostAsJsonAsync("/api/chat/send", new { text, username, source = "bot" });
    if (!resp.IsSuccessStatusCode)
        Console.WriteLine($"Не отправилось ({(int)resp.StatusCode}): {await resp.Content.ReadAsStringAsync()}");
}

// ===== 9. Как выглядит сообщение, которое присылает сайт =====
class ChatMessage
{
    [JsonPropertyName("senderUsername")] public string SenderUsername { get; set; } = "";
    [JsonPropertyName("text")]           public string Text { get; set; } = "";
    [JsonPropertyName("isOwner")]        public bool IsOwner { get; set; }
    [JsonPropertyName("external")]       public bool External { get; set; }
    [JsonPropertyName("source")]         public string? Source { get; set; }
}

Шаг 4. Запусти бота

  1. В терминале (он должен быть в папке ChatBot) напиши: 
    dotnet run
  2. Подожди несколько секунд. Должна появиться строка «Подключён к чату. Жду команды...». Значит, всё работает.
  3. Не закрывай окно терминала: пока оно открыто, бот работает. Чтобы выключить бота, нажми в нём Ctrl+C.

Шаг 5. Проверь

  1. Открой свой чат, например https://partywatcher.de/streamers/baamich.
  2. Напиши !топы. Бот должен ответить списком.
  3. Напиши !рулетка 30. Бот напишет «запускает рулетку», а через 5 секунд назовёт число от 1 до 30.

Как добавить свою команду

Скопируй этот кусок и вставь в код сразу под строкой var text = msg.Text.Trim(); (выше «ПРИМЕР 1 и 2»):

if (text.Equals("!привет", StringComparison.OrdinalIgnoreCase))
{
    await SendAsync($"Привет, {msg.SenderUsername}! 👋");
    return;
}

Что менять: !привет на свою команду, а текст в SendAsync(...) на свой ответ. {msg.SenderUsername} вставит имя того, кто написал. После изменений останови бота (Ctrl+C) и запусти снова (dotnet run).

Не работает?

Что видишьЧто делать
dotnet не найденУстанови .NET SDK (шаг 0) и перезагрузи компьютер.
Бот не пишет «Подключён к чату»Проверь интернет и что в BaseUrl написано ровно https://partywatcher.de. Если всё верно, проверь версию пакета: в папке бота напиши dotnet add package SocketIOClient, чтобы обновить его.
«Не отправилось (401)»Ключ неверный. Скопируй его заново из студии (📋) и вставь между кавычками, без пробелов.
«Не отправилось (429)»Бот пишет слишком часто. Подожди несколько секунд.
Бот подключён, но молчит на командыКоманда должна быть написана точно: !топы, без лишних слов. Перезапусти бота после правок кода.
