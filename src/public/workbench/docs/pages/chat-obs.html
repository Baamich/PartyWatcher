Чат в OBS

Мы покажем чат прямо на твоём стриме. Зрители будут видеть сообщения на экране, а ты не будешь переключаться на сайт.

Что нужно заранее

  • Ты уже вышел в эфир по инструкции (или хотя бы настроил OBS).

Шаг 1. Открой «API чата»

  1. Открой студию: https://partywatcher.de/workbench.html.
  2. Справа найди окно «Чат». Над сообщениями есть тонкая полоска со стрелкой ▲ API чата. Нажми на неё.
  3. Полоска раскроется, окно чата станет выше. Внутри будет поле и кнопки.
вокруг блока ниже -->

Шаг 2. Создай ключ чата

  1. Нажми «🔄 Сгенерировать». В поле появится что-то вроде ****a1b2: это спрятанный ключ, виден только его конец.
  2. Больше ничего копировать не надо, дальше нажимай кнопку со ссылкой.

Шаг 3. Скопируй ссылку для OBS

Нажми кнопку «Ссылка для OBS (Browser Source) 📋». Всё, ссылка у тебя в буфере обмена. Она выглядит так (ключ внутри не показан):

https://partywatcher.de/overlay/chat.html#key=pwc_...

Шаг 4. Добавь чат в OBS

  1. В OBS внизу найди окно Источники и нажми «+».
  2. В списке выбери Браузер (по-английски Browser).
  3. Выбери «Создать новый», назови его, например, Чат, нажми ОК.
  4. В окошке, которое откроется, в поле URL вставь ссылку (Ctrl+V).
  5. Ширина: 400, Высота: 700. (Потом можно растянуть мышкой.)
  6. Найди галку «Выключать источник, когда он не показывается» и сними её. Иначе чат будет пропускать сообщения при смене сцен.
  7. Нажми ОК.

Шаг 5. Поставь чат куда нужно

Чат появится на сцене в виде невидимой рамки. Потяни его мышкой в нужный угол, а за красные точки по краям растяни или сожми.

Проверь

  1. Открой в браузере свой профиль, например https://partywatcher.de/streamers/baamich.
  2. Напиши любое сообщение в чат.
  3. Сообщение должно появиться в OBS. Твой ник будет с красной плашкой.

Простые настройки через ссылку

В конец ссылки можно дописать параметры. Каждый начинается с &:

ДопишиЧто будет
&size=30Текст крупнее (число от 10 до 80)
&fade=40Сообщение пропадает через 40 секунд
&max=15На экране не больше 15 сообщений

Пример: https://partywatcher.de/overlay/chat.html#key=pwc_...&size=30&fade=40

Больше настроек (цвета, шрифт, фон) в главе Стилизация чата.

Не работает?

Что видишьЧто делать
Надпись «В ссылке нет ключа»Ты вставил ссылку без #key=.... Скопируй её заново кнопкой в студии.
Надпись «Неверный ключ чата»Ключ перегенерировали. Скопируй новую ссылку и вставь её в источник (правый клик на источнике → Свойства → URL).
Чат пустойПросто никто ещё ничего не написал. Напиши сам. Если не появилось, в источнике нажми «Обновить кэш текущей страницы».

В ссылке лежит ключ чата. Не показывай её на стриме (например, когда открываешь свойства источника) и никому не отправляй. Подробнее: Безопасность и лимиты.
